# Голосовой помощник: как включить

APK собран **без модели распознавания** — она весит 88 МБ и не помещается
в проект. Лаунчер работает и без неё, просто помощник будет молчать.

Чтобы помощник заговорил, модель надо положить на устройство **один раз**.

## Что делать

1. Скачай русскую модель (44 МБ архив):
   https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

2. Распакуй архив на компьютере.

3. Создай на памяти магнитолы папку и положи туда **содержимое**
   распакованной папки:

```
/sdcard/CarLauncher/vosk-model-ru/
├── am/
├── conf/
├── graph/
├── ivector/
└── README
```

Проверить просто: по пути `/sdcard/CarLauncher/vosk-model-ru/am/final.mdl`
должен лежать файл. Если он там есть — помощник найдёт модель сам.

4. Перезапусти лаунчер.

Лаунчер также ищет модель в `Android/data/com.example.carlauncher/files/vosk-model-ru`,
если так удобнее.

## Почему модель не внутри APK

88 МБ модели раздували APK до 67 МБ и, что важнее, не сохранялись
в проекте между сборками. Отдельная папка надёжнее: модель кладётся
один раз и переживает обновления лаунчера.

# Что было починено (причина падения)

Лаунчер падал при запуске по **двум** причинам сразу.

**1. R8 вырезал Vosk.** Библиотека Vosk работает через JNA, а JNA ищет
классы рефлексией — по строковым именам в рантайме. Оптимизатор R8
таких обращений не видит и считает код неиспользуемым, поэтому вырезал
его из release-сборки. Debug при этом работал, потому что там
минификации нет. Минификацию отключил: на фоне нативных библиотек
на 19 МБ выигрыш от неё всё равно незаметен.

**2. Ошибка не перехватывалась.** Отсутствие нативной библиотеки даёт
`UnsatisfiedLinkError` / `NoClassDefFoundError` — это `Error`, а не
`Exception`. Код ловил `Exception`, ошибка пролетала мимо и роняла
приложение на старте. Теперь везде ловится `Throwable`, и помощник
при любой поломке просто тихо отключается, не трогая лаунчер.

Теперь **отсутствие модели или микрофона не может уронить лаунчер** —
в худшем случае помощник не запустится.
