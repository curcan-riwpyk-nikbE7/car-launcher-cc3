# Как выложить релиз на GitHub (5 минут, без токена)

Репозиторий: https://github.com/curcan-riwpyk-nikbE7/car-launcher-cc3

---

## Шаг 1. Залить исходники (один раз)

Файл готов: **`/home/user/car-launcher-cc3-source.zip`** (319 КБ, 122 файла).
Ключей подписи и APK внутри нет — проверено.

1. Скачайте zip из панели Workspace справа.
2. Распакуйте у себя на компьютере.
3. На GitHub: **Add file → Upload files**.
4. Перетащите **содержимое** папки (не саму папку) в окно браузера.
5. Внизу: **Commit changes**.

---

## Шаг 2. Выложить APK в Releases

Именно отсюда лаунчер берёт обновления.

1. На странице репозитория справа — **Releases → Create a new release**.
2. **Choose a tag** → впишите `v1.0` → **Create new tag: v1.0 on publish**.
3. **Release title**: `1.0 — первая версия`
4. **Describe this release** — текст ниже (см. «Описание релиза»).
5. **Attach binaries** — перетащите ОБА файла:
   - `KINGSAID.apk`
   - `KINGSAID-SYSTEM.apk`
6. **Publish release**.

### Почему два файла
Лаунчер сам выбирает нужный: если он установлен как системный — качает тот, в имени
которого есть `system`, иначе обычный. Подписи у них разные, перепутать нельзя —
установка просто не пройдёт.

---

## Шаг 3. Проверить

На магнитоле: **Настройки → Система → Обновление**.
Должно написать «Установлена последняя версия 1.0».

Если пишет «не удалось проверить» — репозиторий приватный. Сделайте публичным:
**Settings → внизу Danger Zone → Change visibility → Public**.

---

## Как выпускать следующие версии

1. Я поднимаю `versionCode` и `versionName` в `app/build.gradle.kts`
   (сейчас `versionCode = 1`, `versionName = "1.0"`).
2. Собираю и подписываю два APK.
3. Вы делаете новый релиз с тегом на **бо́льшую** версию: `v1.1`, `v1.2` и т.д.

Лаунчер сравнивает версии по числам, не по алфавиту — `1.10` правильно считается
новее `1.9`.

**Важно:** тег релиза должен совпадать с `versionName` в сборке. Если в APK стоит
`1.0`, а тег `v1.0` — лаунчер решит, что обновляться не надо. Для проверки механизма
можно временно поставить тег `v1.1` — тогда он предложит скачать.

## Описание релиза (скопируйте в поле Describe)

```
Лаунчер для TEYES CC3 (UIS7862, Android 10, 1280×720).

Что внутри:
• Интерфейс по образцу штатного лаунчера CC3
• 4 темы: Violet, Blue, Gold, Black
• Голосовой помощник (Vosk, русская модель качается отдельно при первом запуске)
• Плеер с обложкой, автопереключение на карточку телефона при Bluetooth
• Автозапуск Bluetooth-музыки при подключении телефона
• Спидометр, шкала частот радио, погода
• Меню приложений сеткой 3 в ряд, скрытие приложений долгим нажатием
• Запуск приложений в окне (freeform) и на весь экран

Два файла:
• KINGSAID.apk — обычная установка, ставьте этот
• KINGSAID-SYSTEM.apk — только для прошивок с системными правами
  (даёт встраивание приложений прямо в карточку). Подписан ключом AOSP platform,
  на обычной прошивке не установится.

Ставить: скопировать APK на флешку → открыть проводником на магнитоле → установить.
Затем «Кнопка Домой» → выбрать CarLauncher → Всегда.
```

---

## Если исходники заливать не хотите

Можно вообще пропустить Шаг 1 — залить только APK в Releases.
Обновления заработают, репозиторий останется пустым. Для работы лаунчера
исходники на GitHub не нужны, они там только для истории и вашего удобства.
