# Как поставить лаунчер на магнитолу

## Коротко

Собрано **два APK одного и того же лаунчера**. Отличаются только подписью.

| Файл | Что умеет | Куда ставится |
|---|---|---|
| **KINGSAID-SYSTEM.apk** | всё + **приложение внутри карточки** (как штатный) | только на ГУ с прошивкой на ключе AOSP |
| **KINGSAID.apk** | всё, кроме встраивания (отдельное окно) | на любой Android 6+ |

**Начинай с SYSTEM.** Если он не встанет — значит у твоего ГУ свой ключ,
ставь обычный.

---

## Почему это вообще работает

Штатный лаунчер TEYES открывает ютуб и карту прямо в карточке не потому,
что он «умнее», а потому что он **подписан ключом прошивки** и работает
под системным пользователем. Только такому приложению Android отдаёт право
`ACTIVITY_EMBEDDING` — без него чужую активность на свой дисплей не пустить.
Именно из-за его отсутствия мы раньше получали чёрный прямоугольник.

Хорошая новость: подавляющее большинство китайских ГУ (FYT, XYAUTO, TOPWAY,
Unisoc/Spreadtrum — то есть и TEYES тоже) собраны с **дефолтным ключом
`platform` из открытого исходника AOSP**. Производители его не меняют.
Этот ключ лежит в свободном доступе, и мы подписали им системную сборку.

Ровно на этом же держится PIP в известных лаунчерах Dudu и Leco: у них
есть «Public Signature version (high-privilege system signature) supports
PIP, compatible with FYT/XYAUTO/TOPWAY signed with Android testkey».

Отпечаток нашего сертификата:
```
SHA-256: c8:a2:e9:bc:cf:59:7c:2f:b6:dc:66:be:e2:93:fc:13:f2:fc:47:ec:77:bc:6b:2b:0d:52:c1:1f:51:19:2a:b8
```

## Установка

### Шаг 1. Снести старую версию
Если раньше ставил обычную сборку — **удали её**. Подписи разные,
поверх не встанет.

### Шаг 2. Поставить SYSTEM-версию
Копируй `KINGSAID-SYSTEM.apk` на флешку, ставь через файловый менеджер.

**Если установилось** — отлично, ключ совпал, встраивание будет работать.

**Если пишет «Ошибка синтаксического анализа» / «Приложение не установлено»** —
у твоего ГУ ключ другой. Не страшно, ставь `KINGSAID.apk`,
но в карточке приложение будет открываться freeform-окном.

### Шаг 3. Назначить лаунчером по умолчанию
Настройки → Приложения → Приложение «Главный экран» → CarLauncher.
Либо нажать «Домой» и выбрать «Всегда».

### Шаг 4. Проверить режим
Настройки лаунчера → внизу увидишь строку состояния:
- «Системный режим: приложения открываются внутри карточки» — всё получилось
- «Обычный режим» — работает freeform

## Если SYSTEM-версия не встала, но очень хочется

Твоё ГУ (UIS7862, Android 10) рутуется штатно, с флешки, без компьютера —
universal ROOT скрипт для 7862/9863/8141/9853 есть на 4PDA, шьётся как
обновление. С рутом два пути:

1. **Lucky Patcher** — умеет отключать проверку подписи, тогда встанет
   любая сборка с системными правами.
2. **Положить APK в `/system/priv-app/`** вручную — надёжнее всего,
   но придётся повторять после каждого обновления прошивки.

---

## Что именно даёт системная сборка

- `ACTIVITY_EMBEDDING` — чужое приложение рисуется внутри карточки,
  без системной рамки и полоски перетаскивания
- `WRITE_SECURE_SETTINGS` — лаунчер сам включает
  `force_resizable_activities`, поэтому Яндекс Карты и YouTube нормально
  верстаются в маленьком окне, а не обрезаются
- `enable_freeform_support` тоже включается сам — больше не нужен adb

---

## Пересборка

```bash
./build-system-apk.sh     # системная версия
./gradlew :app:assembleStandardRelease   # обычная
```

Ключи AOSP лежат в `keys/`. Они публичные, из открытого исходника Android —
это не «взлом», а просто дефолт, который китайские производители забыли
поменять.

---

## Честно о рисках

- **Работает не на всех ГУ.** Если производитель сгенерировал свой ключ —
  установка просто не пройдёт. Ничего не сломается.
- **Системное приложение сложнее удалить** штатным способом, если оно
  встало как `android.uid.system`. Убирается через adb или откатом.
- **Не все приложения встроятся.** Приложения с защитой контента
  (Netflix, ivi и подобные) покажут чёрное окно — это их DRM, обойти
  нельзя ничем.
- Смена `sharedUserId` — необратимая штука для конкретной установки:
  чтобы вернуться на обычную сборку, надо сначала удалить системную.

# Голосовой помощник (офлайн)

Работает **полностью без интернета**: движок Vosk + русская модель
на 44 МБ лежат внутри APK. Ничего наружу не уходит, в машине без связи
работает так же, как дома.

Из-за модели APK вырос до 67 МБ — это плата за офлайн.

## Как пользоваться

Скажи **«Привет, машина»** (или просто «Машина»), дождись появления
плашки внизу и назови команду. Помощник слушает 6 секунд, потом
возвращается в режим ожидания.

## Что понимает

| Скажи | Что будет |
|---|---|
| выключи экран / погаси экран | гасит подсветку, касание возвращает |
| включи музыку / играй | воспроизведение |
| выключи музыку / пауза / стоп | пауза |
| следующий трек / дальше | следующая песня |
| предыдущий трек | назад |
| громче / тише | шаг громкости |
| намного громче | три шага сразу |
| громкость пятьдесят | ставит 50% |
| громкость на максимум | 100% |
| выключи звук / тишина | в ноль |
| открой карты / включи навигацию | навигатор |
| открой ютуб | видео |
| включи радио | радио |
| открой музыку | запуск плеера (не путать с «включи музыку») |
| открой телефон / настройки / блютуз | соответствующее приложение |
| ночной режим / дневной режим | тема лаунчера |
| какая скорость | называет скорость вслух |
| домой / главный экран | на главный |
| отмена / стой | закрыть помощника |

## Почему это работает точно

Распознавание идёт **по ограниченному словарю**: движок выбирает
из ~90 заранее заданных фраз, а не из всего русского языка. В шумном
салоне это принципиально — точность выше в разы.

Разбор команд покрыт **13 автотестами**. Отдельно проверена самая
опасная пара: «выключи музыку» не должно срабатывать как «включи
музыку» (слово «включи» буквально содержится внутри «выключи»).

## Ограничения — честно

- **Русский TTS.** Голосовые ответы идут через системный синтез речи.
  На китайских ГУ русского голоса часто нет — тогда помощник просто
  показывает ответ на экране. Лечится установкой бесплатного
  **RHVoice** из F-Droid, потом Настройки → Синтез речи → RHVoice.
- **Слово активации при громкой музыке** будет срабатывать плохо:
  микрофон слышит в основном динамики. Это физика, не баг. Если
  окажется совсем неудобно — сделаем кнопку-микрофон на экране
  или повесим на кнопку руля.
- **Выключение экрана по-настоящему** доступно только в SYSTEM-сборке.
  В обычной вместо этого чёрная заглушка поверх — визуально то же
  самое, подсветка при этом остаётся включённой.
- **Первый запуск** распаковывает модель ~5 секунд, дальше мгновенно.
- Микрофон освобождается, когда лаунчер уходит в фон, — чтобы
  не мешать звонкам и навигатору.
