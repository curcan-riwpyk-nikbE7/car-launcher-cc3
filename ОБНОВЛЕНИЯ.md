# Обновления через GitHub

Лаунчер умеет сам проверять новые версии и ставить их.
Репозиторий: `curcan-riwpyk-nikbE7/car-launcher-cc3`

---

## Как проверить обновление

Настройки → **Система** → плитка **«Обновление»**.

Нажатие проверяет сервер. Если версия новее — плитка предложит скачать,
второе нажатие качает APK с прогрессом и открывает установщик.

---

## Как выложить новую версию

1. На GitHub: вкладка **Releases** → **Draft a new release**
2. **Tag**: `v1.1` (буква v в начале, дальше номер)
3. Прикрепить оба файла:
   - `CarLauncher-release.apk`
   - `CarLauncher-SYSTEM.apk`
4. В описание — что нового
5. **Publish release**

Лаунчер сам выберет нужный файл: обычная сборка скачает
`CarLauncher-release.apk`, системная — тот, где в имени есть `SYSTEM`.
Это важно, потому что подписи у них разные и перепутать нельзя.

---

## Обязательно поднимать versionName

В `app/build.gradle.kts`:

```kotlin
versionCode = 2
versionName = "1.1"
```

Без этого лаунчер не увидит обновление: он сравнивает номер версии
из тега релиза с версией установленного приложения.

Сравнение идёт **по числам**, а не по алфавиту — иначе «1.10»
оказалась бы младше «1.9».

---

## Что понадобится на магнитоле

**Разрешение на установку.** При первой попытке Android спросит
«Установка неизвестных приложений» — надо разрешить для CarLauncher.
Иначе установщик не откроется.

**Wi-Fi.** APK весит 30 МБ, по мобильному это заметно.

---

## Почему без токена

Проверка читает публичный API GitHub — авторизация не нужна:

```
api.github.com/repos/curcan-riwpyk-nikbE7/car-launcher-cc3/releases/latest
```

Токен в APK класть нельзя: его вытащит любой, кто распакует файл.
Поэтому релизы выкладываются только вручную, со своего аккаунта.

---

## Ограничения — честно

- **Подпись обязана совпадать.** Обычная сборка обновится только
  обычной, системная — только системной. Разные ключи, поверх не встанет.
- **Автопроверки по расписанию нет** — только по кнопке. Фоновая
  проверка будила бы лаунчер и тратила трафик; если нужна, добавлю.
- Если релизов в репозитории нет, плитка честно скажет
  «Нет связи с сервером» — это нормально до первого релиза.
